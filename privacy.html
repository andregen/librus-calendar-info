Librus calendar

Privacy policy

Effective 7 November 2026. This is a personal integration operated by its account owner, not a public service.

Data accessed and purpose

The integration uses Librus login credentials, linked student identifiers and names, and lesson dates, times, subjects, rooms and change or cancellation information. These are used solely to synchronize the owner's school timetables. Google OAuth credentials authorize creation and maintenance of dedicated calendars. Calendar-list metadata is read to locate those calendars and prevent duplicates.

Storage and sharing

Credentials and private source responses are stored in a restricted directory on the owner's device. OAuth setup runs on the owner's PC; the refresh token is transferred to the device over SSH. Lesson information is sent to Google Calendar in the owner's account. Credentials are sent only to the corresponding provider for authentication. Data is not sold, used for advertising, or used to train AI models.

The optional phone setup page encrypts Librus credentials locally in the browser with RSA-OAEP and AES-GCM. It makes no credential submission request. The owner manually transfers the encrypted result to their PC; only the locally held private key can decrypt it. Do not use the form for anyone else's account.

This documentation site

This public GitHub Pages site contains no schedules, student names, passwords or OAuth tokens. It uses no analytics or third-party scripts. GitHub may process ordinary hosting access logs according to GitHub's privacy statement.

Retention and control

The owner controls local credentials, diagnostics and their retention. Revoke Google access in Google Account permissions, disable the local scheduler, and remove local credentials to stop synchronization. Previously created Google events remain until the owner removes them. Restricted backups may retain earlier local files until the owner deletes them.

Google API data use

Use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Contact the operator through the project issue tracker, without disclosing private data.
